## Отчет о проделанной работе
В данном проекте реализован алгоритм локального выравнивания Смита–Ватермана для аминокислотных последовательностей с использованием матрицы замен (например, BLOSUM62) и аффинных штрафов за пропуски (гэпы). Программа оснащена удобным графическим интерфейсом (GUI) на базе библиотеки `tkinter`.

## Особенности проекта
- **Графический интерфейс:** Удобные окна для загрузки файлов, ввода параметров и просмотра результатов.
- **Поддержка множества форматов:** Программа умеет считывать матрицы и последовательности из форматов `TXT`, `CSV`, `XLSX` и `FASTA`. Парсинг реализован через `pandas` с автоматическим определением разделителей.
- **Аффинные штрафы:** Реализован биологически достоверный расчет штрафов с разделением на открытие пропуска (`gap_open`) и его продолжение (`gap_extend`).
- **Информативный вывод:** Программа не только визуализирует выравнивание, но и автоматически рассчитывает процент идентичности, количество мутаций и генерирует текстовый биологический вывод.
